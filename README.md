# No.86 — Exact shortest reconfiguration distance in CNF formulas parameterized by number of clauses
Ryutaro Yonezu | 2026-11-25 | v1.0 publication candidate

The proof gives theoretical time 2^(6m) poly(n,m) for exact distance (including infinity) between satisfying assignments of a CNF with m clauses. The finite verification scripts and logs are in No86_Reproduction.zip.
